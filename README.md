## Сайт Briaton

Сайт Briaton — это интернет-магазин светильников, где пользователи могут просматривать каталог, выбирать товары и добавлять в корзину. Через бургер-меню «Каталог» можно быстро перейти в нужную категорию. На странице товаров доступны фильтры по типу и наличию, сортировка по цене и популярности, а также пагинация для удобного просмотра.
